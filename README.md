# The Story Within — Hex Map

A minimalist, black-and-white tool for building your life story as a honeycomb of hexagons. Pick an arena (Garden, Hearth, Workshop, Library), assign it to a "thread" (a storyline with its own colour), and it lands on a snaking hex map. Click a thread in the footer to filter the map down to just that storyline.

Everything lives in the browser — there's no backend or database. State is saved to `localStorage` so it persists between visits on the same device.

## Develop

```
npm install
npm run dev
```

## Build

```
npm run build
npm run preview
```
